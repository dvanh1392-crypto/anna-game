# Oẳn tù tì online V3 / 在线猜拳 V3

- 2 người chơi cùng phòng qua mã hoặc link mời.
- Mỗi lượt 5 giây; thắng +1 lượt và quy đổi 500 VND, hòa không cộng.
- Không giới hạn lượt chơi. Bất kỳ người chơi nào bấm Rút lui / 退出游戏 đều kết thúc trận cho cả hai.
- Hỗ trợ tiếng Việt và tiếng Trung giản thể, mỗi thiết bị chọn riêng.
- Số VND chỉ là số liệu quy đổi trong game, không có thanh toán thật.

## Chạy local
`npm install` rồi `npm start` và mở http://localhost:3000.

## Render
Web Service (Node), Build Command: `npm install`, Start Command: `npm start`.

## Lưu ý
Phòng lưu trong RAM, bị mất khi server restart/deploy. Hãy thử bằng hai trình duyệt hoặc hai thiết bị khác nhau.
